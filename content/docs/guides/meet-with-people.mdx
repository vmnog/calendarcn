`PeoplePicker` is the dialog the [live demo](/) opens with <Kbd>F</Kbd> ("Meet with...") and <Kbd>P</Kbd> ("Show teammate calendar..."), and from the same commands in the [Command Menu](/docs/components/command-menu). It searches the provider's `contacts` by name or email, and offers a typed address no contact has. Picking someone meets with them or shows their calendar through [`useCalendarPeople()`](/docs/reference/api#usecalendarpeople), so it goes inside `CalendarProvider`. In the preview, each button opens it in one of its two modes, with the [sample data](/docs/reference/sample-data)'s people.

## Meeting with people

`contacts` are also the people you can meet with, as in Notion Calendar's "Meet with...". `useCalendarPeople()` reads and changes who that is:

- **Meeting with someone** (`meetWith`, `addMeetWith`): their events are drawn in the day and week views behind yours, hatched in their color with their initial, and the times when you and everyone you meet with are free are highlighted, inside `workingHours` (9 AM to 5 PM, Monday to Friday by default) and at least 30 minutes long. An event created meanwhile invites them: its [draft](/docs/guides/creating-events#creating-events) starts with them in its `participants`, waiting for an answer, with the event's calendar account (`calendarEmail`) as the organizer. `addEventFromRange()` invites them the same way.
- **Showing a teammate's calendar** (`teammates`, `addTeammate`): their events are drawn the same way, without a meeting: no free time, no invitations.

Their events come from `contactEvents`, keyed by email. Load them when someone is added (`onMeetWithChange`, `onTeammatesChange`) and when the dates on screen change (`onVisibleRangeChange`). From Google Calendar's free/busy API, which gives busy times without titles, pass an event titled "Busy" for each one. Repeating events work as yours do, and with [`timeZone`](/docs/guides/time-zones#time-zone) or while travelling, their events and the working hours read on the calendar's clock, as yours do. All-day and multi-day events aren't drawn (an all-day event marked `status: "busy"` still takes the day out of the free time), and month, year and agenda views leave other people's events out.

```tsx
const [meetWith, setMeetWith] = React.useState<string[]>([]);
const contactEvents = useFreeBusy(meetWith, visibleRange); // your loader

<CalendarProvider
  defaultEvents={events}
  contacts={contacts}
  meetWith={meetWith}
  onMeetWithChange={setMeetWith}
  contactEvents={contactEvents}
>
  <CalendarSidebar />
  <WeekView />
</CalendarProvider>;
```

The [Calendar Sidebar](/docs/components/calendar-sidebar)'s "Meet with..." field and the [People Picker](/docs/guides/meet-with-people) (F and P in [Calendar App](/docs/components/calendar-app)) add people; your own controls can call `addMeetWith`, `addTeammate` and the rest. `getSharedFreeTime(calendars, days, options)` in `lib/free-busy.ts` computes the highlighted free time, to list it elsewhere: it counts an event as busy unless it's marked `status: "free"`, the calendar's owner declined it, or it's all-day (unless marked busy).

## Usage

```tsx
import { useCalendarShortcuts } from "@/hooks/use-calendar-shortcuts";
import { CalendarProvider } from "@/components/calendar-provider";
import { PeoplePicker } from "@/components/people-picker";
import { WeekView } from "@/components/week-view";
import type { PeoplePickerMode } from "@/components/calendar-types";

export function Schedule() {
  return (
    <CalendarProvider
      defaultEvents={events}
      contacts={contacts}
      contactEvents={contactEvents}
    >
      <CalendarWithPeople />
    </CalendarProvider>
  );
}

function CalendarWithPeople() {
  const [open, setOpen] = React.useState(false);
  const [mode, setMode] = React.useState<PeoplePickerMode>("meet-with");
  const openPicker = (next: PeoplePickerMode) => {
    setMode(next);
    setOpen(true);
  };

  // F and P open it, as in Notion Calendar
  useCalendarShortcuts({
    onMeetWith: () => openPicker("meet-with"),
    onShowTeammateCalendar: () => openPicker("teammate"),
  });

  return (
    <>
      <WeekView />
      <PeoplePicker open={open} onOpenChange={setOpen} mode={mode} />
    </>
  );
}
```

- `"meet-with"` adds the person to the meeting: their events show beside yours and the times you're all free are highlighted. An event you create meanwhile invites them. See [Meeting with people](#meeting-with-people).
- `"teammate"` shows their calendar beside yours, without a meeting.

The people already added are left out of the list. The arrow keys move through it, <Kbd>Enter</Kbd> picks, and <Kbd>Esc</Kbd> closes the picker, which opens empty the next time. The [Calendar Sidebar](/docs/components/calendar-sidebar) lists who was picked, each removable.
