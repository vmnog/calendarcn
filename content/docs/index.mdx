CalendarCN is an open-source calendar for React. It brings the feel of Notion Calendar (fast keyboard navigation, drag to move and resize, a quiet interface) to any app that uses [shadcn/ui](https://ui.shadcn.com) and Tailwind CSS. ## What's included

- **Views**: day, week, any number of days from 2 to 9, month, and an agenda that lists the next 30 days.
- **Direct manipulation**: drag events to move them, drag their edges to resize, click an empty slot to create one.
- **Real calendar data**: overlapping events side by side, multi-day and all-day events, a current-time indicator.
- **Event details**: a side panel or popover with inline editing.
- **Import and export**: read and write .ics files from Google Calendar, Apple Calendar and Outlook. See [Import and Export](/docs/import-export).
- **Keyboard first**: shortcuts for every view, and the live demo's [command menu](/docs/components/command-menu). See [Keyboard shortcuts](/docs/keyboard-shortcuts).
- **Theming**: light and dark mode with the shadcn/ui CSS variables.

## How do I install it? [#install]

Like shadcn/ui, CalendarCN isn't an npm dependency. The shadcn CLI copies the source into your project, so you can read it, restyle it and change how it behaves.

The [Installation](/docs/installation) guide sets up shadcn/ui and adds the `@calendarcn` registry to your `components.json`. Then add the full calendar with one command:

```npm
npx shadcn add @calendarcn/calendar
```

Or add only the pieces you need. Each one pulls in the ones it builds on.

## How do I show my own events? [#your-events]

Pass them in. An event needs an `id`, a `title`, a `start` and an `end`. Give the calendar `defaultEvents` and it owns them, or pass `events` with `onEventsChange` and your app does: every drag, resize, create and edit comes back as the full next list.

```tsx
const [events, setEvents] = React.useState(initialEvents);

<Calendar events={events} onEventsChange={setEvents} />;
```

Already keep them in Google Calendar, Apple Calendar or Outlook? `parseIcs()` turns an exported .ics file into events, and `toIcs()` writes them back out.

## How do I customize it? [#customize]

The CLI copies the source into your project, so you can change the toolbar or the layout right in `components/calendar.tsx`. Before you edit it, check the props: many changes are one prop away.

## What's coming next? [#whats-next]

CalendarCN is built in the open, and plans change as people use it. The Notion-style event details panel shipped most recently. Up next is listing CalendarCN in the shadcn/ui registry directory, next to the other community registries. Later plans include a year view and a resource view, and virtualized rendering for thousands of events.
