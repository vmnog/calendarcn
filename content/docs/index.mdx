CalendarCN is an open-source calendar for React. It brings the feel of Notion Calendar (fast keyboard navigation, drag to move and resize, a quiet interface) to any app that uses [shadcn/ui](https://ui.shadcn.com) and Tailwind CSS.

[Open the live demo](/) to try it.

## Not a package

Like shadcn/ui, CalendarCN isn't an npm dependency. The shadcn CLI copies the source into your project, so you can read it, restyle it and change how it behaves. You can add the full calendar or only the pieces you need.

Start with the [Installation](/docs/installation) guide, then add the full calendar with one command:

```npm
npx shadcn add @calendarcn/calendar
```

See the [Roadmap](/docs/roadmap) for what comes next.

## What's included

- **Views**: day, week, any number of days from 2 to 9, and month.
- **Direct manipulation**: drag events to move them, drag their edges to resize, click an empty slot to create one.
- **Real calendar data**: overlapping events side by side, multi-day and all-day events, a current-time indicator.
- **Event details**: a side panel or popover with inline editing.
- **Keyboard first**: shortcuts for every view and a command menu. See [Keyboard shortcuts](/docs/keyboard-shortcuts).
- **Theming**: light and dark mode with the shadcn/ui CSS variables.
