Event Details shows the selected event in a side panel. When the panel is closed, the same details open in a popover next to the event. Fields edit in place.

## Features

- Edit the title in place. The event on the calendar updates as you type.
- Edit the start and end times. <Kbd>Enter</Kbd> saves, <Kbd>Esc</Kbd> cancels.
- Right-click an event to change its color or calendar, or to cut, copy or duplicate it.
