`EventDetailPanel` shows an event's details and edits them in place. The views open it in a popover beside the selected event, and you can render it yourself anywhere, such as a side panel. It needs an event, and `onEventChange` to edit it: without a change handler the panel is read-only. Inside a `CalendarProvider` it uses the provider's clock and locale, and its `calendars`, `contacts`, `rooms`, `conferenceProviders` and `locationSuggestions`. On its own it uses the defaults: no calendars to pick, contacts, rooms, conferencing services or place suggestions.

## Usage

```tsx
import { EventDetailPanel } from "@/components/event-detail-panel";

export function EventSidebar() {
  const [event, setEvent] = React.useState(initialEvent);

  return <EventDetailPanel event={event} onEventChange={setEvent} />;
}
```

To show the selected event of a calendar in a side panel, read it from `useCalendar()` and turn the popover off on the view:

```tsx
function SidePanel() {
  const { selectedEvent, updateEvent } = useCalendar<DetailedCalendarEvent>();
  if (!selectedEvent) return null;

  return <EventDetailPanel event={selectedEvent} onEventChange={updateEvent} />;
}

<CalendarProvider defaultEvents={events}>
  <WeekView showEventPopover={false} />
  <SidePanel />
</CalendarProvider>;
```

Leave out `onEventChange` to show an event read-only, for example one from a calendar people can only view. The title and the other fields don't accept typing and the menus that change the event are disabled, so no edit looks saved when it isn't.

```tsx
<EventDetailPanel event={event} />
```

The repeat row's arrows step through a series. In the views' popover they work on their own: the provider finds the selected event's neighbors (`previousInSeries` and `nextInSeries` from `useCalendar()`, `null` at the series' ends) and `showSeriesOccurrence` selects one and moves to it. An occurrence your events have no event for yet is added as a copy of the selected event, through `onEventsChange` and `onEventCreate`. Pass the same to a panel you render yourself:

```tsx
const { previousInSeries, nextInSeries, showSeriesOccurrence } =
  useCalendar<DetailedCalendarEvent>();

<EventDetailPanel
  event={selectedEvent}
  onEventChange={updateEvent}
  onPrevWeek={
    previousInSeries ? () => showSeriesOccurrence(previousInSeries) : undefined
  }
  onNextWeek={
    nextInSeries ? () => showSeriesOccurrence(nextInSeries) : undefined
  }
/>;
```

Outside a provider, `findSeriesOccurrence(events, event, "next")` (from `@/lib/recurrence`) finds the occurrence: the event when you have one for it, else its start and an id, for `createSeriesOccurrence(event, occurrence)` to copy the event to. The copy's id names the day it stands for, so it stays that day's occurrence after it is moved or renamed. A series is the events with the same title, calendar and rule; a `recurrenceRule` counts its days in the event's `timeZone`, so a 9 AM New York series stays at 9 AM there across daylight saving changes.

## Conference providers

The Conferencing row adds a video call from the services in the provider's `conferenceProviders`. Nothing is on by default: with no services the row is hidden, unless the event already has a call. To offer the live demo's Google Meet, Zoom and Microsoft Teams, install them and pass them in:

<InstallTabs item="conference-providers" />

```tsx
import { DEMO_CONFERENCE_PROVIDERS } from "@/lib/conference-providers";

<CalendarProvider conferenceProviders={DEMO_CONFERENCE_PROVIDERS}>
  <WeekView />
</CalendarProvider>;
```

`Calendar` takes the same prop.

They're placeholders. Each `createConference` makes up a call in the service's code format (`abc-defg-hij` for Meet) on `example.com`, after 400ms so the row's pending state shows, and no link opens a real meeting. Before people rely on them, make `createConference` create the meeting through the service's API and return its link. The API needs your credentials, so call it from your server:

```tsx
import type { ConferenceProviderOption } from "@/components/calendar-types";

const conferenceProviders: ConferenceProviderOption[] = [
  {
    provider: "zoom",
    label: "Zoom",
    icon: <ZoomLogo />,
    createConference: async (event) => {
      // Your route creates the meeting with Zoom's API
      const response = await fetch("/api/zoom-meetings", {
        method: "POST",
        body: JSON.stringify({ title: event.title, start: event.start }),
      });
      if (!response.ok) throw new Error("Zoom didn't create the meeting");
      const meeting = await response.json();
      return { provider: "zoom", url: meeting.joinUrl, meetingId: meeting.id };
    },
  },
];
```

A rejected promise adds no call. Labels must be unique, so you can offer one service twice, like two Zoom accounts.

Google Meet, Zoom and Microsoft Teams logos are their owners' trademarks, so the item ships none and the row shows a camera for each service. The live demo adds the logos itself. To show them, pass your own as `icon` (16px), taken from each service's brand resources and used under its terms.

## Features

- Edit the title in place. With `onEventChange` wired to the calendar, the event updates as you type.
- Pick the start and end times from a menu in 15-minute steps. End times show how long the event lasts (`1h 30min`).
- Type a time and the menu lists what it can mean, daytime first: `7` gives 7 PM, then 7 AM. In the end field a number is also a duration: `45` gives 45 minutes later.
- Hovering a time previews it. <Kbd>Enter</Kbd>, a click, or leaving the field after typing or arrow keys saves it. <Kbd>Esc</Kbd> restores the old value.
- Pick dates from a date picker, or type one (`Nov 12`). From the input, <Kbd>↑</Kbd> and <Kbd>↓</Kbd> move a day, and <Kbd>Page Up</Kbd> and <Kbd>Page Down</Kbd> a month.
- Switch an event to all-day and back: it gets its own times back, or 9–10 AM when it had none.
- Time options follow the wall clock, so they stay right on the days daylight saving time starts and ends.
- In every menu and list of the details, <Kbd>Esc</Kbd> closes it and restores the value from before it opened. Arrow keys and the pointer only preview: the time zone list shows the highlighted city in the field until <Kbd>Enter</Kbd> or a click picks it.
- Pick the event's time zone from a searchable list of every zone, with recent and popular ones first. The times keep their wall-clock value in the new zone, so the event moves on the grid, which (like the panel's times) stays in the viewer's zone: 2 PM in New York becomes 2 PM in Tokyo, which is 1 AM New York time.
- Set a repeat rule from Notion's presets or the custom dialog (every N days, weeks, months or years, on chosen days, on the 1st to 4th or last weekday of the month, until a date or N times). `.ics` import and export keep it as an RRULE; an RRULE the details can't show reads "Custom repeat".
- Fields the event doesn't set (participants, AI meeting notes, location, links, description, reminders) show Notion's muted placeholders. So does conferencing when the provider passes `conferenceProviders`; without them the row is hidden, unless the event already has a call.
- Invite participants. Focusing the field lists the provider's recent `contacts`; typing filters them and offers a typed email address. The calendar's account (`calendarEmail`) joins as the organizer with the first guest, and stays while anyone is invited. Each guest shows their response (accepted, declined or maybe) and "Organizer" or "Optional"; hover a guest to copy their email, email them, mark them optional or remove them. <Kbd>Esc</Kbd> closes the list and never invites anyone.
- Book meeting rooms from the provider's `rooms`, under "View rooms and resources" or by typing a room's name.
- Add a video call from one of the provider's `conferenceProviders`. While an async `createConference` runs, the row shows the service as pending; then it shows the service's icon, name (a link that joins the call) and meeting code, with buttons to copy the link and to switch service or remove the call.
- Type a location: the typed text is listed first, then the matching `locationSuggestions`. A location that's a web address opens itself. Any other location links to a Google Maps search, so clicking it sends the location text to Google.
- Turn AI meeting notes on or off. This only sets the event's `aiMeetingNotes` flag: the panel doesn't record or write notes.
- Add a link from "Add links and attachments": paste or type an address and press <Kbd>Enter</Kbd>. A bare domain like `example.com` gets `https://`, and text that isn't a link is dropped. Hover a link, or <Kbd>Tab</Kbd> onto it, to see its address with a copy button.
- Attach a file from the same menu. The panel keeps its name, size and type with a `blob:` URL; nothing is uploaded.
- Edit the description in place: the event takes the text when you leave it, and <Kbd>Esc</Kbd> restores it. Web addresses in it become links, and are also listed after the event's links.
- Move the event to another of the provider's `calendars` (grouped by account) or give it its own color, set it busy or free and pick who can see it, from menus that open beside the panel. Hovering a choice previews it; <Kbd>Esc</Kbd> closes the menu and keeps the old value.
- Add reminders from presets, or type a number to get it in minutes, hours, days or weeks ("2h", "10 mins"), up to 4 weeks before. Reminders stay sorted, and one that fires with another ("60min" and "1hour") isn't added twice. Adding one closes the list, and typing opens it again. Hover a reminder to remove it.
- Right-click an event on the calendar to change its color or calendar, or to cut, copy or duplicate it.

## Custom details

<ComponentPreview name="custom-event-details-demo" />

Pass `renderEventDetails` to `CalendarProvider` to replace the popover's body. It gets the selected event, a `close` function and `isNew`, which is true right after the event was created by clicking an empty slot, so you can focus its title. Render a component from it when you need hooks: `useCalendar()` to save edits, `useCalendarConfig()` to format times like the calendar does.

## Build your own panel

`EventDetailPanel` is one component per section, and they install with it. Render the ones you need, in your own order, to build a smaller panel or a different layout. Each section takes `EventDetailSectionProps`: the `event`, and `onEventChange`, without which the section is read-only.

```tsx
import type { EventDetailSectionProps } from "@/components/calendar-types";
import { EventDetailParticipants } from "@/components/event-detail-participants";
import {
  EventDetailDivider,
  EventDetailGroup,
} from "@/components/event-detail-parts";
import { EventDetailTime } from "@/components/event-detail-time";

export function CompactDetails({
  event,
  onEventChange,
}: EventDetailSectionProps) {
  return (
    <div className="flex flex-col text-sm font-medium">
      <EventDetailGroup name="when">
        <EventDetailTime event={event} onEventChange={onEventChange} />
      </EventDetailGroup>
      <EventDetailDivider />
      <EventDetailGroup name="who">
        <EventDetailParticipants event={event} onEventChange={onEventChange} />
      </EventDetailGroup>
    </div>
  );
}
```
