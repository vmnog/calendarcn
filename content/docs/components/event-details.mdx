`EventDetailPanel` shows an event's details and edits them in place. The views open it in a popover beside the selected event, and you can render it yourself anywhere, such as a side panel. It only needs an event and a change handler. Inside a `CalendarProvider` it follows the provider's clock and locale; on its own it uses the defaults.

## Usage

```tsx
import { EventDetailPanel } from "@/components/event-detail-panel";

export function EventSidebar() {
  const [event, setEvent] = React.useState(initialEvent);

  return <EventDetailPanel event={event} onEventChange={setEvent} />;
}
```

To show the selected event of a calendar in a side panel, read it from `useCalendar()` and turn the popover off on the view:

```tsx
function SidePanel() {
  const { selectedEvent, updateEvent } = useCalendar<DetailedCalendarEvent>();
  if (!selectedEvent) return null;

  return <EventDetailPanel event={selectedEvent} onEventChange={updateEvent} />;
}

<CalendarProvider defaultEvents={events}>
  <WeekView showEventPopover={false} />
  <SidePanel />
</CalendarProvider>;
```

The repeat row's arrows step through a series. In the views' popover they work on their own: the provider finds the selected event's neighbors (`previousInSeries` and `nextInSeries` from `useCalendar()`, `null` at the series' ends) and `showSeriesOccurrence` selects one and moves to it. An occurrence your events have no event for yet is added as a copy of the selected event, through `onEventsChange`. Pass the same to a panel you render yourself:

```tsx
const { previousInSeries, nextInSeries, showSeriesOccurrence } =
  useCalendar<DetailedCalendarEvent>();

<EventDetailPanel
  event={selectedEvent}
  onEventChange={updateEvent}
  onPrevWeek={
    previousInSeries ? () => showSeriesOccurrence(previousInSeries) : undefined
  }
  onNextWeek={
    nextInSeries ? () => showSeriesOccurrence(nextInSeries) : undefined
  }
/>;
```

Outside a provider, `findSeriesOccurrence(events, event, "next")` (from `@/lib/recurrence`) finds the occurrence: the event when you have one for it, else its start and an id, for `createSeriesOccurrence(event, occurrence)` to copy the event to. The copy's id names the day it stands for, so it stays that day's occurrence after it is moved or renamed. A series is the events with the same title, calendar and rule; a `recurrenceRule` counts its days in the event's `timeZone`, so a 9 AM New York series stays at 9 AM there across daylight saving changes.

## Features

- Edit the title in place. With `onEventChange` wired to the calendar, the event updates as you type.
- Edit the start and end times and dates. <Kbd>Enter</Kbd> saves, <Kbd>Esc</Kbd> restores the old value.
- In every menu and list of the details, <Kbd>Esc</Kbd> closes it and restores the value from before it opened. Arrow keys and the pointer only preview: the time zone list shows the highlighted city in the field until <Kbd>Enter</Kbd> or a click picks it.
- Pick the event's time zone from a searchable list of every zone, with recent and popular ones first. The times keep their wall-clock value in the new zone, so the event moves on the grid, which (like the panel's times) stays in the viewer's zone: 2 PM in New York becomes 2 PM in Tokyo, which is 1 AM New York time.
- Set a repeat rule from Notion's presets or the custom dialog (every N days, weeks, months or years, on chosen days, on the 1st to 4th or last weekday of the month, until a date or N times). `.ics` import and export keep it as an RRULE; an RRULE the details can't show reads "Custom repeat".
- Fields the event doesn't set (participants, conferencing, location, links, description, reminders) show Notion's muted placeholders.
- Right-click an event on the calendar to change its color or calendar, or to cut, copy or duplicate it.

## Custom details

<ComponentPreview name="custom-event-details-demo" />

Pass `renderEventDetails` to `CalendarProvider` to replace the popover's body. It gets the selected event, a `close` function and `isNew`, which is true right after the event was created by clicking an empty slot, so you can focus its title. Render a component from it when you need hooks: `useCalendar()` to save edits, `useCalendarConfig()` to format times like the calendar does.
