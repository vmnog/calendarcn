`EventDetailPanel` shows an event's details and edits them in place. The views open it in a popover beside the selected event, and you can render it yourself anywhere, such as a side panel. It only needs an event and a change handler. Inside a `CalendarProvider` it follows the provider's clock and locale; on its own it uses the defaults.

## Installation

<InstallTabs item="event-details" />

## Usage

```tsx
import { EventDetailPanel } from "@/components/event-detail-panel";

export function EventSidebar() {
  const [event, setEvent] = React.useState(initialEvent);

  return <EventDetailPanel event={event} onEventChange={setEvent} />;
}
```

To show the selected event of a calendar in a side panel, read it from `useCalendar()` and turn the popover off on the view:

```tsx
function SidePanel() {
  const { selectedEvent, updateEvent } = useCalendar<DetailedCalendarEvent>();
  if (!selectedEvent) return null;

  return <EventDetailPanel event={selectedEvent} onEventChange={updateEvent} />;
}

<CalendarProvider defaultEvents={events}>
  <WeekView showEventPopover={false} />
  <SidePanel />
</CalendarProvider>;
```

Leave out `onEventChange` to show an event read-only, for example one from a calendar people can only view. The title and the other fields don't accept typing and the menus that change the event are disabled, so no edit looks saved when it isn't.

```tsx
<EventDetailPanel event={event} />
```

## Features

- Edit the title in place. With `onEventChange` wired to the calendar, the event updates as you type.
- Pick the start and end times from a menu in 15-minute steps. End times show how long the event lasts (`1h 30min`).
- Type a time and the menu lists what it can mean, daytime first: `7` gives 7 PM, then 7 AM. In the end field a number is also a duration: `45` gives 45 minutes later.
- Hovering a time previews it. <Kbd>Enter</Kbd>, a click, or leaving the field after typing or arrow keys saves it. <Kbd>Esc</Kbd> restores the old value.
- Pick dates from a date picker, or type one (`Nov 12`). From the input, <Kbd>↑</Kbd> and <Kbd>↓</Kbd> move a day, and <Kbd>Page Up</Kbd> and <Kbd>Page Down</Kbd> a month.
- Switch an event to all-day and back: it gets its own times back, or 9–10 AM when it had none.
- Time options follow the wall clock, so they stay right on the days daylight saving time starts and ends.
- Fields the event doesn't set (participants, conferencing, location, links, description, reminders) show Notion's muted placeholders.
- Right-click an event on the calendar to change its color or calendar, or to cut, copy or duplicate it.

## Custom details

<ComponentPreview name="custom-event-details-demo" />

Pass `renderEventDetails` to `CalendarProvider` to replace the popover's body. It gets the selected event, a `close` function and `isNew`, which is true right after the event was created by clicking an empty slot, so you can focus its title. Render a component from it when you need hooks: `useCalendar()` to save edits, `useCalendarConfig()` to format times like the calendar does.

## Build your own panel

`EventDetailPanel` is one component per section, and they install with it. Render the ones you need, in your own order, to build a smaller panel or a different layout. Each section takes `EventDetailSectionProps`: the `event`, and `onEventChange`, without which the section is read-only.

```tsx
import type { EventDetailSectionProps } from "@/components/calendar-types";
import { EventDetailParticipants } from "@/components/event-detail-participants";
import {
  EventDetailDivider,
  EventDetailGroup,
} from "@/components/event-detail-parts";
import { EventDetailTime } from "@/components/event-detail-time";

export function CompactDetails({
  event,
  onEventChange,
}: EventDetailSectionProps) {
  return (
    <div className="flex flex-col text-sm font-medium">
      <EventDetailGroup name="when">
        <EventDetailTime event={event} onEventChange={onEventChange} />
      </EventDetailGroup>
      <EventDetailDivider />
      <EventDetailGroup name="who">
        <EventDetailParticipants event={event} onEventChange={onEventChange} />
      </EventDetailGroup>
    </div>
  );
}
```
