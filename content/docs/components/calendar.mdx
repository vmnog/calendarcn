## What's in the block

- A header with today, previous and next buttons and a view switcher.
- A left sidebar with a mini calendar and the list of calendars.
- A right sidebar with the details of the selected event.
- A command menu (<KbdGroup><Kbd>⌘</Kbd><Kbd>K</Kbd></KbdGroup>) and the full set of [keyboard shortcuts](/docs/keyboard-shortcuts).
- Light and dark mode.
