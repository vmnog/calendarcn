The time grid lays out days as columns and hours as rows. [Day View](/docs/components/day-view) and [Week View](/docs/components/week-view) are both built on it, and you can use it directly for a custom layout.

<Callout title="Coming with the view split">
  `TimeGrid` doesn't exist as its own export yet. Today the grid lives inside
  `WeekView`, which already renders the day view when the provider's view is
  `"day"`. The usage below is the planned API.
</Callout>

## Features

- A time axis, a column per day and a current-time indicator.
- An all-day row for all-day and multi-day events.
- Overlapping events placed side by side.
- Drag an event to move it, including to another day. The grid scrolls when you reach its edge.
- Drag the top or bottom edge of an event to resize it.
- Click an empty slot to create an event.
- Visible hours, snap step and clock come from [`CalendarProvider`](/docs/components/calendar-core#calendarprovider): `dayStartHour`, `dayEndHour`, `snapMinutes` and `hourCycle`.

## Usage

```tsx
import { CalendarProvider } from "@/components/calendar-provider";
import { TimeGrid } from "@/components/time-grid";

export function Agenda() {
  return (
    <CalendarProvider defaultEvents={events}>
      <div className="h-[600px]">
        <TimeGrid view="week" />
      </div>
    </CalendarProvider>
  );
}
```
