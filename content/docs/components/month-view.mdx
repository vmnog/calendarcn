Month View shows six weeks at a time. Timed events are listed in each day, all-day and multi-day events run across days as bars, and busy days collapse the rest into a "more" button. Like every view, it reads its state from the surrounding [`CalendarProvider`](/docs/reference/api).

<InstallTabs item="month-view" />

## Usage

```tsx
import { CalendarProvider } from "@/components/calendar-provider";
import { MonthView } from "@/components/month-view";

export function MonthlyPlan() {
  return (
    <CalendarProvider defaultView="month" defaultEvents={events}>
      {/* Month View fills its parent's height */}
      <div className="h-[600px]">
        <MonthView />
      </div>
    </CalendarProvider>
  );
}
```

Set `defaultView="month"` (or control `view`) so the provider snaps the date, header and navigation to months. To switch between month and week, see the [Calendar](/docs/components/calendar) example.

## Examples

### Your own toolbar

Month View has no header of its own. In month view, `goToPrev()` and `goToNext()` from [`useCalendar()`](/docs/reference/api#usecalendar) move a month, and `monthName` follows the month on screen.

### Monday start and week numbers

`defaultWeekStartsOn={1}` starts the weeks on Monday, and the `showWeekNumbers` [view setting](/docs/guides/customise-the-look#view-settings) numbers them.

### A busy day

A day with more events than fit shows "N more". Clicking it switches the provider to the week view, so render [Week View](/docs/components/day-week-view) for it.

### Your own event content

[`renderEventContent`](/docs/guides/customise-the-look#custom-event-content) draws the inside of each event: `placement` is `"month-item"` for a line in a day and `"month-bar"` for a bar across days.

## Features

- Drag an event to another day, or drag the ends of a bar to change its dates.
- Double-click a day's empty space to create an all-day event, or press and drag across days to draw one over them. See [Creating events](/docs/guides/creating-events#creating-events).
- "N more" on a busy day calls `showDay()`, which switches the provider to the week view and briefly highlights that day. Render [Week View](/docs/components/day-week-view) for that view, as the [Calendar](/docs/components/calendar) example does; with Month View alone the button has nothing to show.
- Scroll vertically to move through weeks. Scrolling snaps to the nearest week.
- Hide weekends, show week numbers or hide the events you declined through the provider's view settings. Declined events are struck through while they show.
- Move a focused event a day with <KbdGroup><Kbd>Alt</Kbd><Kbd>←</Kbd></KbdGroup> / <KbdGroup><Kbd>Alt</Kbd><Kbd>→</Kbd></KbdGroup>, or a week with <KbdGroup><Kbd>Alt</Kbd><Kbd>↑</Kbd></KbdGroup> / <KbdGroup><Kbd>Alt</Kbd><Kbd>↓</Kbd></KbdGroup>. See [Keyboard & accessibility](/docs/components/calendar#keyboard--accessibility).

<Callout title="Scrolling over the preview">
