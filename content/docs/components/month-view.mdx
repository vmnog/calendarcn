Month View shows six weeks at a time. Timed events are listed in each day, all-day and multi-day events run across days as bars, and busy days collapse the rest into a "more" button. Like every view, it reads its state from the surrounding [`CalendarProvider`](/docs/components/calendar-core).

## Usage

```tsx
import { CalendarProvider } from "@/components/calendar-provider";
import { MonthView } from "@/components/month-view";

export function MonthlyPlan() {
  return (
    <CalendarProvider defaultView="month" defaultEvents={events}>
      {/* Month View fills its parent's height */}
      <div className="h-[600px]">
        <MonthView />
      </div>
    </CalendarProvider>
  );
}
```

Set `defaultView="month"` (or control `view`) so the provider snaps the date, header and navigation to months. To switch between month and week, see the [Calendar](/docs/components/calendar) example.

## Features

- Drag an event to another day, or drag the ends of a bar to change its dates.
- "N more" on a busy day calls `showDay()`, which switches the provider to the week view and briefly highlights that day. Render [Week View](/docs/components/week-view) for that view, as the [Calendar](/docs/components/calendar) example does; with Month View alone the button has nothing to show.
- Scroll vertically to move through weeks. Scrolling snaps to the nearest week.
- Hide weekends or show week numbers through the provider's view settings.
- Move a focused event a day with <KbdGroup><Kbd>Alt</Kbd><Kbd>←</Kbd></KbdGroup> / <KbdGroup><Kbd>Alt</Kbd><Kbd>→</Kbd></KbdGroup>, or a week with <KbdGroup><Kbd>Alt</Kbd><Kbd>↑</Kbd></KbdGroup> / <KbdGroup><Kbd>Alt</Kbd><Kbd>↓</Kbd></KbdGroup>. See [Keyboard & accessibility](/docs/components/calendar#keyboard--accessibility).

<Callout title="Scrolling over the preview">
