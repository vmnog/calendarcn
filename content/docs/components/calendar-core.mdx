Calendar Core has no UI of its own. `CalendarProvider` holds the calendar's state (the current date, the active view, the events and the selected event), and `useCalendar()` reads and updates it from any component inside the provider. Every view and the event details build on it.

## Planned settings

The provider is where calendar-wide settings will live. Names and defaults are still being decided:

- Snap interval for dragging and resizing events.
- Visible hour range of the time grid.
- 12-hour or 24-hour clock.
- A [date-fns locale](https://date-fns.org/docs/I18n) for dates, weekdays and the first day of the week.
- Number of days in the week view.
