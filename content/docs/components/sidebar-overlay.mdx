Sidebar Overlay shows a sidebar's content as a modal sheet from the left or the right. The [Calendar Sidebar](/docs/components/calendar-sidebar) and the [Details Sidebar](/docs/components/details-sidebar) use it on phones. It's the same sheet as shadcn/ui's `Sidebar` on mobile, but you own its open state and the breakpoint, so a sidebar can turn into an overlay at any width.

## Installation

<InstallTabs item="sidebar-overlay" />

It also adds the sidebars' color tokens to your CSS: see [Colors](/docs/components/calendar-sidebar#colors).

## Usage

```tsx
import { SidebarOverlay } from "@/components/sidebar-overlay";

export function MobileNav() {
  const [open, setOpen] = React.useState(false);

  return (
    <>
      <Button onClick={() => setOpen(true)}>Menu</Button>
      <SidebarOverlay
        open={open}
        onOpenChange={setOpen}
        side="left"
        title="Navigation"
        description="Pages of the app."
        style={{ "--sidebar-width": "15rem" } as React.CSSProperties}
      >
        <nav>{/* ... */}</nav>
      </SidebarOverlay>
    </>
  );
}
```

The sheet is as wide as `--sidebar-width`, up to 85% of the screen. Its title and description are for screen readers only.

## Features

- Closes on an outside tap and <Kbd>Esc</Kbd>, with focus kept inside while it's open.
- Opening focuses the sheet itself, not its first field, so a search field doesn't pop up a phone's keyboard.
- Works with shadcn/ui on Radix and on Base UI.
