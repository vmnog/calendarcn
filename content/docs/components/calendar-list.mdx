Calendar List is the list of calendars in the [Calendar Sidebar](/docs/components/calendar-sidebar). Calendars are grouped under their account's email, each account collapsible, each calendar with its color. Hover a calendar to show its eye button and hide it; a subscribed calendar, like a holidays feed, gets a feed icon.

## Usage

The list lists the `calendars` of the surrounding [`CalendarProvider`](/docs/components/calendar-core), the same ones the event details' calendar picker offers. It's built from shadcn/ui's sidebar parts, so it needs a `SidebarProvider` around it.

```tsx
import { CalendarList } from "@/components/calendar-list";
import type { CalendarInfo } from "@/components/calendar-types";

const calendars: CalendarInfo[] = [
  {
    id: "personal",
    name: "Personal",
    color: "purple",
    email: "you@example.com",
  },
  {
    id: "holidays",
    name: "Holidays",
    color: "green",
    email: "you@example.com",
    isSubscribed: true,
  },
  { id: "work", name: "Work", color: "blue", email: "you@work.example.com" },
];

<CalendarProvider defaultEvents={events} calendars={calendars}>
  <SidebarProvider>
    <CalendarList />
  </SidebarProvider>
</CalendarProvider>;
```

Outside a provider, pass `calendars` yourself. Hiding a calendar only dims its row: read the hidden ids with `onHiddenCalendarIdsChange` to filter your events, or set them with `hiddenCalendarIds`.

```tsx
const [hidden, setHidden] = React.useState<string[]>([]);

<CalendarList
  calendars={calendars}
  hiddenCalendarIds={hidden}
  onHiddenCalendarIdsChange={setHidden}
/>;
```
