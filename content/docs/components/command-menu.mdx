`CommandMenu` is the [live demo](/)'s <KbdGroup><Kbd>⌘</Kbd><Kbd>K</Kbd></KbdGroup> menu, built on shadcn/ui's [Command](https://ui.shadcn.com/docs/components/command) in a Dialog. Creating an event, going to a date, today, previous and next, and the day, week, month, year and agenda views come from [`useCalendar()`](/docs/components/calendar-core#usecalendar), so it goes inside `CalendarProvider`. Commands that belong to your app, such as its panels, event search, the shortcut list, its theme and .ics files, show only when you pass their callback.

## Usage

```tsx
import { useCalendarShortcuts } from "@/hooks/use-calendar-shortcuts";
import { CalendarProvider } from "@/components/calendar-provider";
import { CommandMenu } from "@/components/command-menu";
import { WeekView } from "@/components/week-view";

export function Schedule() {
  return (
    <CalendarProvider defaultEvents={events}>
      <CalendarWithMenu />
    </CalendarProvider>
  );
}

function CalendarWithMenu() {
  const [open, setOpen] = React.useState(false);

  // ⌘K / Ctrl+K opens and closes the menu, even from a text field
  useCalendarShortcuts({ onToggleCommandMenu: () => setOpen((o) => !o) });

  return (
    <>
      <WeekView />
      <CommandMenu open={open} onOpenChange={setOpen} />
    </>
  );
}
```

The menu is controlled: it opens and closes through `open` and `onOpenChange`, and closes before it runs a command. The preview opens it from a button, to leave <KbdGroup><Kbd>⌘</Kbd><Kbd>K</Kbd></KbdGroup> to this site's search.

### Go to date

"Go to date..." turns the menu's field into a date field, as in Notion Calendar. Type a date and the menu shows the day it reads, with its weekday, so you can check "next friday" before going there. <Kbd>Enter</Kbd> shows that day's period in the current view and briefly highlights it (`navigateToDate`). <Kbd>Esc</Kbd> closes the menu without moving, and <Kbd>⌫</Kbd> in the empty field goes back to the commands.

It reads "today", "tomorrow", weekdays ("friday", "next friday", "last monday"), "next week", "next month", "in 2 weeks", "3 days ago", "+3d", a month and day in either order ("dec 25", "25 december", "December 25th, 2027", "sept 5"), a month alone ("jan"), a numeric date in the locale's order ("12/25", or "25/12" in en-GB, "25.12." in German) and "2027-12-25". A date without a year is the next one from today, and weeks start on the provider's `weekStartsOn`. Month and weekday names work in the provider's `locale` and in English. The parser is `parseDateQuery()` in `lib/date-query.ts`, which the CLI installs with the menu:

```ts
import { parseDateQuery } from "@/lib/date-query";

parseDateQuery("next friday", { today: new Date(), locale, weekStartsOn });
// → the Friday of next week, at midnight, or null when the text isn't a date
```

To open the menu straight on Go to date, as the <Kbd>.</Kbd> key does in the demo, pass `defaultPage="go-to-date"` before opening it:

```tsx
const [page, setPage] = React.useState<CommandMenuPage>("commands");

useCalendarShortcuts({
  onToggleCommandMenu: () => {
    setPage("commands");
    setOpen((o) => !o);
  },
  onGoToDate: () => {
    setPage("go-to-date");
    setOpen(true);
  },
});

<CommandMenu open={open} onOpenChange={setOpen} defaultPage={page} />;
```

### Create event

"Create event..." (<Kbd>C</Kbd> outside the menu) creates an hour-long event at the next half hour, as Notion Calendar does: on today when it's on screen, else on the first day shown (`addEventAtNextSlot`). It goes through your `createEvent`, so undo and the details work as for a clicked slot, and the new event's title is focused.

### Your app's commands

Pass a callback to add its command. These are the demo's:

```tsx
<CommandMenu
  open={open}
  onOpenChange={setOpen}
  onToggleSidebar={toggleSidebar}
  onToggleContextPanel={toggleContextPanel}
  onCycleTheme={cycleTheme}
  onImportIcs={() => fileInputRef.current?.click()}
  onExportIcs={exportIcs}
  onSearchEvents={(query) => detailsActions.current?.searchEvents(query)}
  onShowShortcuts={() => detailsActions.current?.showAllShortcuts()}
  showComingSoon
/>
```

- `onImportIcs` and `onExportIcs` add "Import .ics file..." and "Export .ics file". Read and write the files with [`@calendarcn/ics`](/docs/import-export): the demo opens a hidden `<input type="file">`, passes its text to `parseIcs()` and adds the events, and downloads `toIcs(events)` as a file.
- `onCycleTheme` adds "Set theme...". The demo goes from system to light to dark with `useTheme()` from next-themes.
- `onSearchEvents` adds "Search events", and once you type, "Search events for “…”" with your text. The demo opens the [Details Sidebar](/docs/components/details-sidebar)'s event search with the field focused.
- `onShowShortcuts` adds "Show keyboard shortcuts" (<Kbd>?</Kbd>). The demo shows the details sidebar's full list.
- `onToggleSidebar` and `onToggleContextPanel` add the panel toggles, next to the [Calendar Header](/docs/components/calendar-header)'s buttons.
- `showComingSoon` also lists the Notion Calendar commands CalendarCN doesn't have yet, disabled with a "Soon" badge, as the demo does.

### Time zones

The "Time zones" commands come from `useCalendar()`, like going to today and the views, so they work in any calendar:

- "Travel to time zone..." draws the calendar in another zone for now, with your home zone beside it. See [Travel to a time zone](/docs/components/calendar-core#travel-to-a-time-zone).
- "Show additional time zones..." adds a zone's column beside the time axis.
- With more than one zone, "Make time zone primary..." and "Hide time zone..." pick one of the zones shown.

Each opens a list of zones in the menu's place, searched by city, zone name or offset ("Tokyo", "Japan", "+9"). <Kbd>⌫</Kbd> in an empty search goes back to the commands. Pass `timeZoneCommand="travel"` to open the menu on its list: the demo does that for <Kbd>Z</Kbd>, with [`useCalendarShortcuts({ onTravelToTimeZone })`](/docs/keyboard-shortcuts#app-shortcuts).

### Keyboard shortcuts

The menu shows each command's shortcut. Pass the same callbacks to [`useCalendarShortcuts()`](/docs/keyboard-shortcuts#app-shortcuts) to turn the keys on:

```tsx
useCalendarShortcuts({
  onToggleCommandMenu: () => setOpen((o) => !o),
  onToggleSidebar: toggleSidebar,
  onToggleContextPanel: toggleContextPanel,
  onCycleTheme: cycleTheme,
});
```

### Theming

The dialog is translucent and blurred in dark mode. The CLI also adds a rule to your CSS file that dims the page less behind the menu in dark mode (`rgb(0 0 0 / 0.3)`), found through the `data-command-menu` attribute on the dialog. The rest of the look comes from your own `command` and `dialog` components.
