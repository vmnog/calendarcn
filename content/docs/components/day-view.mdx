Day View shows a single day on the [Time Grid](/docs/components/time-grid), with the same drag, resize and create interactions as the week view. Rendered on its own, it sets the provider's view to `"day"`, so prev/next, <Kbd>T</Kbd> and the header step by one day.

## Installation

<InstallTabs item="day-view" />

## Usage

```tsx
import { CalendarProvider } from "@/components/calendar-provider";
import { DayView } from "@/components/day-view";

export function Today() {
  return (
    <CalendarProvider defaultEvents={events}>
      <div className="h-[600px]">
        <DayView scrollToHour={8} />
      </div>
    </CalendarProvider>
  );
}
```
