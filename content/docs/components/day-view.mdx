Day View shows a single day on the [Time Grid](/docs/components/time-grid), with the same drag, resize and create interactions as the week view. In the demo, press <Kbd>D</Kbd> or <Kbd>1</Kbd> to switch to it.

<Callout title="Coming with the view split">
  `DayView` doesn't exist as its own export yet. Until it does, `WeekView`
  renders a single day when the provider's view is `"day"`:
  `<CalendarProvider defaultView="day">` with `<WeekView />` inside.
</Callout>

## Usage

{/* TODO: check this against src/components/day-view.tsx after the split. */}

```tsx
import { CalendarProvider } from "@/components/calendar-provider";
import { DayView } from "@/components/day-view";

export function Today() {
  return (
    <CalendarProvider defaultView="day" defaultEvents={events}>
      <div className="h-[600px]">
        <DayView />
      </div>
    </CalendarProvider>
  );
}
```
