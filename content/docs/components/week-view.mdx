Week View shows several days side by side on the [Time Grid](/docs/components/time-grid): an all-day row on top, an hour grid below. It reads the date, events and selection from the surrounding [`CalendarProvider`](/docs/components/calendar-core), so it has almost no props of its own.

## Installation

<InstallTabs item="week-view" />

## Usage

```tsx
import { CalendarProvider } from "@/components/calendar-provider";
import { WeekView } from "@/components/week-view";

export function Schedule() {
  return (
    <CalendarProvider defaultEvents={events}>
      {/* Week View fills its parent's height */}
      <div className="h-[600px]">
        <WeekView scrollToHour={8} />
      </div>
    </CalendarProvider>
  );
}
```

Show fewer days with the provider's `numberOfDays` (or `defaultNumberOfDays`). Below 7, the columns start on the current day and previous/next move by that many days.

```tsx
<CalendarProvider defaultEvents={events} defaultNumberOfDays={3}>
  <WeekView />
</CalendarProvider>
```

## Features

- Drag an event to move it, including to another day. The grid scrolls when you reach its edge.
- Drag the top or bottom edge of an event to resize it.
- Click an empty slot to create an event, then type its title.
- Click an event to open its details in a popover. Right-click it for color, calendar and copy actions.
- Overlapping events sit side by side. All-day and multi-day events sit in the all-day row.
- Scroll sideways to move through days. Scrolling snaps to the nearest day.
- Touch: long-press an event to drag it.
- Move and resize from the keyboard. See [Keyboard & accessibility](/docs/components/calendar#keyboard--accessibility).
