Calendar Settings is the live demo's settings dialog, laid out as Notion Calendar's: on the left, General and each calendar account, then "Add calendar account"; on the right, the pane you picked. Open it in the [live demo](/) with <KbdGroup><Kbd>⌘</Kbd><Kbd>,</Kbd></KbdGroup> or "Go to settings" in the command menu.

- **General**: the calendar view (weekends, declined events, week numbers, and the number of days in week view), the time format and the theme.
- **A calendar account**: its calendars, each with its color and a button to show or hide it.

Each setting shows only when something can change it, so the dialog fits what your app supports. The calendar view settings come from the surrounding [`CalendarProvider`](/docs/reference/api); the time format, the theme, hiding calendars and "Add calendar account" show when you pass their handlers.

## Usage

Render it inside your `CalendarProvider`, and open it from a button, a command or <KbdGroup><Kbd>⌘</Kbd><Kbd>,</Kbd></KbdGroup>:

```tsx
import { useTheme } from "next-themes";

import { useCalendarShortcuts } from "@/hooks/use-calendar-shortcuts";
import { CalendarSettingsDialog } from "@/components/calendar-settings";

function Settings({ hourCycle, onHourCycleChange }) {
  const [open, setOpen] = React.useState(false);
  const { theme, setTheme } = useTheme();

  // ⌘, (Ctrl+, elsewhere) opens it, even from a text field
  useCalendarShortcuts({ onOpenSettings: () => setOpen(true) });

  return (
    <CalendarSettingsDialog
      open={open}
      onOpenChange={setOpen}
      theme={theme}
      onThemeChange={setTheme}
      onHourCycleChange={onHourCycleChange}
    />
  );
}
```

The time format sets the provider's `hourCycle`, so keep it in state and pass it to `CalendarProvider`. The dialog reads the current one from the provider.

### Calendar accounts

The accounts are the provider's `calendars`, grouped by their `email` as in the [Calendar List](/docs/components/calendar-sidebar#calendar-list). Pass the hidden calendars and their handler to show or hide each from its account's pane, and `onAddCalendarAccount` to list "Add calendar account":

```tsx
<CalendarSettingsDialog
  open={open}
  onOpenChange={setOpen}
  defaultSection="calendars"
  hiddenCalendarIds={hiddenCalendarIds}
  onHiddenCalendarIdsChange={setHiddenCalendarIds}
  onAddCalendarAccount={connectAccount}
/>
```

`defaultSection="calendars"` opens it on the first account, as "Manage calendar accounts" does in the live demo. [Calendar App](/docs/components/calendar-app) renders the dialog for you with `settingsDialog`.
