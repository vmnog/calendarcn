---
title: Keyboard shortcuts
description: Move around the calendar without touching the mouse.
---

These shortcuts work in the [live demo](/). Single-key shortcuts pause while you type in an input.

## Navigation

| Action          | Shortcut                                      |
| --------------- | --------------------------------------------- |
| Go to today     | <Kbd>T</Kbd>                                  |
| Previous period | <Kbd>J</Kbd> or <Kbd>←</Kbd>                  |
| Next period     | <Kbd>K</Kbd> or <Kbd>→</Kbd>                  |
| Command menu    | <KbdGroup><Kbd>⌘</Kbd><Kbd>K</Kbd></KbdGroup> |

## Views

| Action           | Shortcut                     |
| ---------------- | ---------------------------- |
| Day view         | <Kbd>D</Kbd> or <Kbd>1</Kbd> |
| Week view        | <Kbd>W</Kbd> or <Kbd>0</Kbd> |
| Show 2 to 9 days | <Kbd>2</Kbd> to <Kbd>9</Kbd> |
| Month view       | <Kbd>M</Kbd>                 |

## Panels

| Action               | Shortcut                                      |
| -------------------- | --------------------------------------------- |
| Toggle left sidebar  | <KbdGroup><Kbd>⌘</Kbd><Kbd>/</Kbd></KbdGroup> |
| Toggle right sidebar | <Kbd>/</Kbd>                                  |

## Events

| Action                | Shortcut                                                  |
| --------------------- | --------------------------------------------------------- |
| Deselect event        | <Kbd>Esc</Kbd>                                            |
| Show or hide weekends | <KbdGroup><Kbd>⇧</Kbd><Kbd>⌘</Kbd><Kbd>E</Kbd></KbdGroup> |
| Show or hide declined | <KbdGroup><Kbd>⇧</Kbd><Kbd>⌘</Kbd><Kbd>D</Kbd></KbdGroup> |

## Appearance

| Action                            | Shortcut                                      |
| --------------------------------- | --------------------------------------------- |
| Cycle theme (system, light, dark) | <KbdGroup><Kbd>⇧</Kbd><Kbd>M</Kbd></KbdGroup> |

On Windows and Linux, use <Kbd>Ctrl</Kbd> in place of <Kbd>⌘</Kbd>. The one exception is the left sidebar toggle, which needs the <Kbd>⌘</Kbd> (Meta) key.
