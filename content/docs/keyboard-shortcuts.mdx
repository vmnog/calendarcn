---
title: Keyboard shortcuts
description: Move around the calendar without touching the mouse.
---

The [Calendar](/docs/components/calendar) block and the [live demo](/) share a set of single-key shortcuts. Single-key shortcuts pause while you type in an input, and leave presses with <Kbd>⌘</Kbd> or <Kbd>Ctrl</Kbd> to your app and the browser.

They come from `useCalendarShortcuts()`, part of [Calendar Core](/docs/components/calendar-core), not from the views. A calendar you build from the views alone only handles keys while one of its events has focus: see [Keyboard & accessibility](/docs/components/calendar#keyboard--accessibility) for moving and resizing events from the keyboard.

## Navigation

| Action          | Shortcut                     |
| --------------- | ---------------------------- |
| Go to today     | <Kbd>T</Kbd>                 |
| Previous period | <Kbd>J</Kbd> or <Kbd>←</Kbd> |
| Next period     | <Kbd>K</Kbd> or <Kbd>→</Kbd> |

## Views

| Action           | Shortcut                     |
| ---------------- | ---------------------------- |
| Day view         | <Kbd>D</Kbd> or <Kbd>1</Kbd> |
| Week view        | <Kbd>W</Kbd> or <Kbd>0</Kbd> |
| Show 2 to 9 days | <Kbd>2</Kbd> to <Kbd>9</Kbd> |
| Month view       | <Kbd>M</Kbd>                 |
| Agenda view      | <Kbd>A</Kbd>                 |

## Events

| Action                | Shortcut                                                  |
| --------------------- | --------------------------------------------------------- |
| Deselect event        | <Kbd>Esc</Kbd>                                            |
| Show or hide weekends | <KbdGroup><Kbd>⇧</Kbd><Kbd>⌘</Kbd><Kbd>E</Kbd></KbdGroup> |
| Show or hide declined | <KbdGroup><Kbd>⇧</Kbd><Kbd>⌘</Kbd><Kbd>D</Kbd></KbdGroup> |

In a field or menu of the event details, <Kbd>Esc</Kbd> only closes it and restores the value from before. Press it again to deselect the event.

## App shortcuts

The live demo adds keys for the parts around the calendar. They come from the same hook, each one on only when you pass its action, so a calendar without a command menu or panels never claims them:

| Action                            | Shortcut                                      | Option                 |
| --------------------------------- | --------------------------------------------- | ---------------------- |
| Command menu                      | <KbdGroup><Kbd>⌘</Kbd><Kbd>K</Kbd></KbdGroup> | `onToggleCommandMenu`  |
| Toggle the sidebar                | <KbdGroup><Kbd>⌘</Kbd><Kbd>/</Kbd></KbdGroup> | `onToggleSidebar`      |
| Toggle the context panel          | <Kbd>/</Kbd>                                  | `onToggleContextPanel` |
| Cycle theme (system, light, dark) | <KbdGroup><Kbd>⇧</Kbd><Kbd>M</Kbd></KbdGroup> | `onCycleTheme`         |
| Settings                          | <KbdGroup><Kbd>⌘</Kbd><Kbd>,</Kbd></KbdGroup> | `onOpenSettings`       |

```tsx
useCalendarShortcuts({
  onToggleCommandMenu: () => setCommandMenuOpen((open) => !open),
  onToggleSidebar: toggleSidebar,
  onToggleContextPanel: toggleContextPanel,
  onCycleTheme: cycleTheme,
});
```

On Windows and Linux, use <Kbd>Ctrl</Kbd> in place of <Kbd>⌘</Kbd>. The one exception is the sidebar toggle, which needs the <Kbd>⌘</Kbd> (Meta) key. <KbdGroup><Kbd>⌘</Kbd><Kbd>K</Kbd></KbdGroup> and <KbdGroup><Kbd>⌘</Kbd><Kbd>,</Kbd></KbdGroup> work from inside a text field too. The [Command Menu](/docs/components/command-menu) and the [Calendar Header](/docs/components/calendar-header) show these keys next to their commands and buttons.

## Use them in your own calendar

The Calendar block turns them on for you. In a calendar you compose yourself, call the hook anywhere inside `CalendarProvider`:

```tsx
import { useCalendarShortcuts } from "@/hooks/use-calendar-shortcuts";

function Shortcuts() {
  useCalendarShortcuts();
  return null;
}

<CalendarProvider defaultEvents={events}>
  <Shortcuts />
  <WeekView />
</CalendarProvider>;
```

The hook listens on `window`, so one calendar per page should have it.

### Turn them off

Pass `shortcuts={false}` to the Calendar block, or `useCalendarShortcuts({ enabled: false })` to the hook, for example while a dialog of yours is open.

### Change them

The hook is your code: the keys live in `handleShortcut()` and `handleAppShortcut()` in `hooks/use-calendar-shortcuts.ts`, so remap or remove them there. The app keys are checked before the calendar's, and one that runs stops the event from reaching later `keydown` listeners. To give your app another key the calendar also uses, handle it in a `keydown` listener added before the hook's and call `event.stopImmediatePropagation()`.
