---
title: Registry items
description: Every item the shadcn CLI can add, what it adds, and what it pulls in.
---

Add any of these with `npx shadcn@latest add`, as in [Installation](/docs/installation#add-components).

| Item                               | What it adds                                                                                                                                                                                                                                                                                                                                                |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@calendarcn/calendar`             | The full calendar: toolbar, view switcher and keyboard shortcuts over the day, week, month, year and agenda views.                                                                                                                                                                                                                                          |
| `@calendarcn/calendar-app`         | The live demo as one block: both sidebars, the header, the views, the ⌘K menu, theme switching, .ics import and export, and the shortcuts. Brings the sample data. See [Calendar App](/docs/components/calendar-app).                                                                                                                                       |
| `@calendarcn/calendar-core`        | Types, event layout math, `CalendarProvider`, `useCalendar()`, `useCalendarShortcuts()` and the color tokens. Repeat rules in `@/lib/recurrence` (`parseRecurrence`, `formatRRule`, `describeRecurrenceRule`, `expandRecurringEvents`, `findSeriesOccurrence`) and time zones in `@/lib/time-zones` (`getEventTimeZone`, `changeTimeZoneKeepingWallClock`). |
| `@calendarcn/time-grid`            | The hour grid behind the day and week views, with drag, resize and create.                                                                                                                                                                                                                                                                                  |
| `@calendarcn/day-view`             | One day on the time grid.                                                                                                                                                                                                                                                                                                                                   |
| `@calendarcn/week-view`            | A week, or any number of days, on the time grid.                                                                                                                                                                                                                                                                                                            |
| `@calendarcn/month-view`           | The month grid, with drag and resize.                                                                                                                                                                                                                                                                                                                       |
| `@calendarcn/agenda-view`          | The coming days' events as a scrolling list, grouped by day.                                                                                                                                                                                                                                                                                                |
| `@calendarcn/year-view`            | The year as twelve month grids, with today and the days that have events marked.                                                                                                                                                                                                                                                                            |
| `@calendarcn/event-details`        | Event chips, the detail panel, the details popover and the right-click menu.                                                                                                                                                                                                                                                                                |
| `@calendarcn/ics`                  | `parseIcs()` and `toIcs()`: read and write .ics files from Google Calendar, Apple Calendar and Outlook.                                                                                                                                                                                                                                                     |
| `@calendarcn/conference-providers` | Placeholder Google Meet, Zoom and Microsoft Teams for the details' Conferencing row, to pass to `conferenceProviders`. See [Conference providers](/docs/components/event-details#conference-providers).                                                                                                                                                     |
| `@calendarcn/sample-data`          | The live demo's events, calendars, contacts, rooms and places, and the docs examples' week of events. See [Sample Data](/docs/sample-data).                                                                                                                                                                                                                 |
| `@calendarcn/calendar-header`      | The live demo's header: month and year with the period on screen, view switcher, today, previous/next and panel toggles. Also its parts, for a header of your own.                                                                                                                                                                                          |
| `@calendarcn/command-menu`         | The live demo's ⌘K menu: today, previous/next and the views, plus your app's panel, theme and .ics commands.                                                                                                                                                                                                                                                |
| `@calendarcn/calendar-toaster`     | Notion Calendar's toasts after a delete, a cut or a copy, with Undo. See [Calendar Toaster](/docs/components/calendar-toaster).                                                                                                                                                                                                                             |
| `@calendarcn/calendar-settings`    | Notion Calendar's settings dialog: the calendar view, time format and theme, and each account's calendars.                                                                                                                                                                                                                                                  |
| `@calendarcn/people-picker`        | The dialog <Kbd>F</Kbd> and <Kbd>P</Kbd> open: search your contacts to meet with someone or show a teammate's calendar. See [People Picker](/docs/components/people-picker).                                                                                                                                                                                |
| `@calendarcn/calendar-sidebar`     | The demo's left sidebar: mini calendar, scheduling, "Meet with...", calendar list and theme toggle, inline or as an overlay.                                                                                                                                                                                                                                |
| `@calendarcn/mini-calendar`        | The sidebar's month picker, with week numbers and the visible days highlighted.                                                                                                                                                                                                                                                                             |
| `@calendarcn/calendar-list`        | The calendars grouped by account, each with a show and hide button.                                                                                                                                                                                                                                                                                         |
| `@calendarcn/theme-toggle`         | A button that cycles system, light and dark, with the next-themes provider.                                                                                                                                                                                                                                                                                 |
| `@calendarcn/details-sidebar`      | The demo's right context panel: the selected event's details, event search and useful shortcuts.                                                                                                                                                                                                                                                            |
| `@calendarcn/sidebar-overlay`      | A sidebar as a modal sheet on narrow screens, and the sidebars' color tokens.                                                                                                                                                                                                                                                                               |

Each item pulls in the ones it builds on, so `calendar` installs all of them except `day-view` and `week-view`, which it doesn't need (it renders the time grid directly), `ics`, which you add to import or export .ics files, `conference-providers` and `sample-data`, which you add to try the calendar with the live demo's services and data, and `command-menu`, `people-picker`, `calendar-toaster`, `calendar-settings` and the sidebars, which you add around it. `calendar-sidebar` installs the mini calendar, calendar list, theme toggle and sidebar overlay. `calendar-app` installs everything the live demo uses, `ics`, `conference-providers`, `sample-data`, `command-menu`, `people-picker`, `calendar-toaster`, `calendar-settings` and both sidebars included.
